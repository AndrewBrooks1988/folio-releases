# Folio releases

Installers and update files for **Folio**, a light, focused Markdown reader and editor for Windows.

Download the latest installer from [Releases](../../releases/latest).

Folio checks this repository for updates. Each release contains:

- `Folio_<version>_x64-setup.exe`: the installer
- `Folio_<version>_x64-setup.exe.sig`: its update signature
- `latest.json`: what Folio reads to find the newest version

The source code is kept separately.
